# VCam iOS

VCam replaces the live camera preview with a photo or video selected from the Photos library.

- Supports image and video replacement for front and rear live camera previews.
- Preserves the selected media file and its original image or video resolution.
- Plays selected videos continuously and loops them automatically.
- Provides controls to move, rotate, and zoom the replacement media.
- Includes a separate draggable floating Control button.
- Supports enabling or disabling camera replacement at any time.
- Includes optional runtime logs for troubleshooting.
